# PII IoT – Kinect mit Raspberry Pi 4

## Ziel
Echte RGB-Bilder und später Tiefendaten mit einer Xbox 360 Kinect erfassen.

## Hardware
- Raspberry Pi 4
- Xbox 360 Kinect mit Netzteil

## Software
- Raspberry Pi OS / Linux
- Python 3
- libfreenect

## Projektstruktur
- src/: Python-Programme
- data/: lokale Testbilder und Videos
- config/: Konfiguration für die Edge-Verbindung

## Aktueller Stand
- RGB-Bilder erfolgreich empfangen
- Ein RGB-Testbild als PNG gespeichert
- Tiefendaten und Live-Übertragung an Edge noch zu testen
